# Bank Melli USD Rate Dashboard

یک داشبورد ساده Streamlit برای گزارش روزانه نرخ دلار بانک ملی و مقایسه آن با نرخ بازار.

## نصب

```bash
pip install -r requirements.txt
```

## اجرا

```bash
streamlit run app.py
```

## منبع داده

داده ها از یک Google Sheet منتشر شده به صورت CSV خوانده می شوند. آدرس CSV در فایل `config.py` قرار دارد.
